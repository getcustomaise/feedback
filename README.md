# Customaise Feedback & Changelog

This repo is the public hub for **Customaise** — the AI-powered Chrome extension for userscripts.

No code lives here. This is where you can:

- 🐛 **Report bugs** → [New Bug Report](https://github.com/getcustomaise/feedback/issues/new?template=bug_report.md)
- 💡 **Request features** → [New Feature Request](https://github.com/getcustomaise/feedback/issues/new?template=feature_request.md)
- 📋 **Read the changelog** → [CHANGELOG.md](./CHANGELOG.md)
- 💬 **Join discussions** → [Discussions tab](https://github.com/getcustomaise/feedback/discussions)
