# Customaise Feedback

This repo is the public hub for Customaise, the Chrome extension that lets you fix, customize, and automate any website with AI. UserScripts, AgentScripts for AI agents to call, and a real MCP server for your IDE.

No code lives here. This is where you can:

- **Report bugs** at [New Bug Report](https://github.com/getcustomaise/feedback/issues/new?template=bug_report.md)
- **Request features** at [New Feature Request](https://github.com/getcustomaise/feedback/issues/new?template=feature_request.md)
- **Read the changelog** at [CHANGELOG.md](./CHANGELOG.md)
- **Join discussions** in the [Discussions tab](https://github.com/getcustomaise/feedback/discussions)
