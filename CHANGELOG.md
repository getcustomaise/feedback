# Customaise Changelog

All notable changes to the Customaise Chrome extension will be documented here.

## [0.6.0] - 2026-03-23

### Added
- **MCP Server** — Connect AI coding agents (Cursor, Claude Code, Windsurf, Antigravity) to Customaise via `npx -y @customaise/mcp`. 12 tools for script management, browser context, and automation.
- **AI Chat** — Describe what you want in plain English; Gemini writes and installs the script for you.
- **Version History** — Full commit-level history for every script with diff viewer and one-click restore.
- **Script Import/Export** — Standard `.user.js` format compatible with Tampermonkey and Violentmonkey.
- **DOM Selector Tool** — Point-and-click element targeting that generates bulletproof selectors.
- **Built-in Editor** — Monaco editor with syntax highlighting, AST validation, and symbol navigation.
- **Cross-device Sync** — Encrypted script synchronization across Chrome instances (Power User).
- **Customaise Toolbox** — Pre-installed utility script with frequently requested web enhancements.
